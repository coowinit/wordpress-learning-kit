8. 紧急重置管理员密码（简易临时方案）

紧急维护
<?php /** * 临时重置 WordPress 管理员密码 * * 使用方法： * 1. 先备份 functions.php。 * 2. 修改下面的管理员用户名和新密码。 * 3. 将本段代码临时添加到当前主题的 functions.php。 * 4. 访问：https://你的域名/?reset_admin=1 * 5. 页面提示成功后，立即删除本段代码并保存。 * 6. 使用新密码登录 WordPress 后台。 * * 安全提醒： * - 仅在紧急情况下短暂使用。 * - 代码启用期间，知道触发网址的人可能重置指定账户的密码。 * - 成功后立即删除，不要长期保留。 * - 不要将填写真实密码的版本提交到 GitHub。 */ add_action( 'init', function () { // 修改为需要重置的管理员用户名。 $username = 'admin'; // 修改为新的强密码，建议至少 16 位。 $new_password = 'YourNewPassword123!'; // 只有访问 ?reset_admin=1 时才执行。 if ( ! isset( $_GET['reset_admin'] ) || '1' !== $_GET['reset_admin'] ) { return; } // 查找用户，并确认具有管理员权限。 $user = get_user_by( 'login', $username ); if ( ! $user || ! user_can( $user, 'manage_options' ) ) { wp_die( '管理员账号不存在或权限不足。' ); } // 使用 WordPress 原生函数重置密码。 wp_set_password( $new_password, $user->ID ); // 结束本次请求，提示立即删除临时代码。 wp_die( '密码重置成功！请立即删除 functions.php 中的这段临时代码。' ); } );
适用于无法通过主机面板或 WP-CLI 恢复账户时的临时应急操作。代码启用期间存在被他人触发的风险，成功后立即删除整段代码。
