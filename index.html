学习说明

这个版本重点偏向代码知识，不再只讲后台概念。每个页面都围绕真实使用场景整理多个代码片段，例如 hooks、主题资源、模板、CPT、媒体、菜单、后台设置、插件架构、短代码、Gutenberg、Elementor、表单、AJAX、SEO、安全、性能、迁移和调试。

除了 HTML 页面，所有代码也同步整理到了 snippets/ 文件夹中，方便你用 VS Code 打开研究。
